## Chi tiết từng Gap

### G1 — `Lobbies` thiếu 3 columns

**Tại sao Critical:** EF sẽ throw `InvalidOperationException` khi load `Lobby.ActiveSession` vì FK column không tồn tại. App sẽ crash khi truy vấn bất kỳ lobby nào có navigation property `ActiveSession`.

**Source of truth:**

- Entity: `BoardVerse.Core/Entities/Lobby.cs`
- Config: `BoardVerse.Data/Configurations/LobbyConfiguration.cs`
- DB: production branch `br-hidden-shadow-aoqtn6su`

**3 columns còn thiếu:**

| Column | Type | Nullable | Default | Notes |
|--------|------|----------|---------|-------|
| `CancellationLeadTimeMinutes` | `integer` | NOT NULL | `30` | BR-08: phút trước giờ hẹn để trigger auto-hủy |
| `FullAt` | `timestamptz` | NULL | — | BR-LOBBY-READY-03: mốc thời gian lobby chuyển sang FULL |
| `ActiveSessionId` | `uuid` | NULL | — | FK → `ActiveSessions.Id` ON DELETE SET NULL |

**Config relationship (đã có, column không tồn tại):**
```csharp
// LobbyConfiguration.cs
builder.HasOne(l => l.ActiveSession)
    .WithMany()
    .HasForeignKey(l => l.ActiveSessionId)
    .OnDelete(DeleteBehavior.SetNull);
```

**SQL fix:**
```sql
ALTER TABLE "Lobbies"
  ADD COLUMN IF NOT EXISTS "CancellationLeadTimeMinutes" integer NOT NULL DEFAULT 30;

ALTER TABLE "Lobbies"
  ADD COLUMN IF NOT EXISTS "FullAt" timestamptz NULL;

ALTER TABLE "Lobbies"
  ADD COLUMN IF NOT EXISTS "ActiveSessionId" uuid NULL;

ALTER TABLE "Lobbies"
  ADD CONSTRAINT "FK_Lobbies_ActiveSessions_ActiveSessionId"
  FOREIGN KEY ("ActiveSessionId")
  REFERENCES "ActiveSessions" ("Id")
  ON DELETE SET NULL;

CREATE INDEX IF NOT EXISTS "IX_Lobbies_ActiveSessionId"
  ON "Lobbies" ("ActiveSessionId");
```

> ⚠️ Constraint FK đã tồn tại (báo lỗi `already exists` là bình thường nếu chạy lại). Chỉ cần 3 lệnh `ADD COLUMN`.

### G2 — `CafeConfigs` thiếu 2 columns

**Tại sao HIGH:** Entity `CafeConfig.cs` có 2 properties không được EF map vì config thiếu. Giá trị được gán trong memory nhưng **không persist xuống DB** — feature BR-DEPOSIT-03 (deposit rate cap per person) không hoạt động.

**Source of truth:**

- Entity: `BoardVerse.Core/Entities/CafeConfig.cs` (lines 48-60)
- Config: `BoardVerse.Data/Configurations/ReservationConfiguration.cs` → `CafeConfigConfiguration`
- DB: production `CafeConfigs` table

**2 columns còn thiếu:**

| Column | Type | Nullable | Default | Notes |
|--------|------|----------|---------|-------|
| `MinDepositRatePerPerson` | `bigint` | NOT NULL | `1` | BR-DEPOSIT-03: floor BVC/person (1 BVC = 1.000 VND) |
| `MaxDepositRatePerPerson` | `bigint` | NOT NULL | `100` | BR-DEPOSIT-03: ceiling BVC/person (100 BVC = 100.000 VND) |

**Config (thiếu 2 dòng này):**
```csharp
// CafeConfigConfiguration.cs — THIẾU:
builder.Property(c => c.MinDepositRatePerPerson).HasDefaultValue(1L);
builder.Property(c => c.MaxDepositRatePerPerson).HasDefaultValue(100L);
```

**SQL fix:**
```sql
ALTER TABLE "CafeConfigs"
  ADD COLUMN IF NOT EXISTS "MinDepositRatePerPerson" bigint NOT NULL DEFAULT 1;

ALTER TABLE "CafeConfigs"
  ADD COLUMN IF NOT EXISTS "MaxDepositRatePerPerson" bigint NOT NULL DEFAULT 100;
```

### G4 — `SeatInventories.RowVersion` type conflict (schema drift)

**Tại sao MEDIUM:** Config khai báo column type `xid` (PostgreSQL transaction ID) nhưng DB lưu `bigint`. Đây là **schema drift** — nếu chạy `dotnet ef migrations add` sẽ sinh migration để alter column. Ứng dụng hiện tại không crash nhưng `dotnet ef database update` sẽ báo out-of-sync.

**Source of truth:**

- Config: `BoardVerse.Data/Configurations/ReservationConfiguration.cs` → `SeatInventoryConfiguration`
```csharp
builder.Property(s => s.RowVersion)
    .IsRowVersion()
    .HasColumnName("xmin")
    .HasColumnType("xid");
```
- Entity: `BoardVerse.Core/Entities/SeatInventory.cs` — property `uint RowVersion`
- DB: column `RowVersion` type `bigint`

**SQL fix:**
```sql
BEGIN;
ALTER TABLE "SeatInventories"
  ALTER COLUMN "RowVersion" TYPE xid
  USING ("RowVersion"::xid);
COMMIT;
```

> ⚠️ Cast từ `bigint` sang `xid` yêu cầu giá trị là integer hợp lệ. Nếu bảng đang có data, kiểm tra trước:
> ```sql
> SELECT "RowVersion" FROM "SeatInventories" LIMIT 5;
> ```
> Nếu giá trị > 2^32 (4.294.967.296), cần xử lý riêng.
